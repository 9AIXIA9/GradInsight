
# GradInsight - 高考生高校选择助手平台

## 一、项目背景与痛点

高考志愿填报时，很多同学和家长会遇到信息不透明、专业不了解、学校真实情况难以获知等问题。


## 二、项目定位与目标

GradInsight 是一个面向高考生和家长的高校信息与志愿决策辅助平台，聚合了真实的校园体验和专业信息，帮你更好地了解学校和专业，做出适合自己的选择。

核心目标：

- 展示真实、全面的高校信息
- 提供志愿填报决策支持
- 让高考生和在校生/校友有更多交流


## 三、核心业务场景

### 1. 真实校园信息展示

- 浏览各高校真实环境、设施、氛围的内容
- 校友分享学习和生活体验

### 2. 专业选择指导

- 提供专业详情、课程、就业数据等
- 支持兴趣和分数匹配推荐

### 3. 志愿填报决策支持

- 历年录取数据风险评估
- 个性化志愿推荐
- 模拟填报和结果预测


## 四、核心功能模块

### 1. 高校信息系统

- 学校基础信息、环境、地理、文化等

### 2. 专业指导系统

- 专业详情、就业前景、兴趣匹配等


## 五、用户群体分析

### 1. 高考生

- 了解真实校园和专业，获得志愿决策支持

### 2. 家长

- 帮助孩子了解学校和专业，辅助决策

## 六、系统价值与创新点

### 社会价值

- 降低志愿填报风险，提升信息透明度

### 创新点

1. 校友认证的真实体验分享
2. 结合兴趣和能力的专业推荐
3. 多维度志愿决策模型

---

GradInsight 希望让高考志愿填报变得更简单、更透明。欢迎体验和反馈。
